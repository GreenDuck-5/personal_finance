# Personal Finance

Our program is a program that allows you to sign in and do things surrounding income, expenses, savings, and any other budgeting catigories you'd like!

![Image of running code](location)

## How to Use
Before running our program, you need to type installation commands into your terminal
### Things to Install:
- customtkinter
    - Enter 'pip install customtkinter' into your terminal
- numpy
    - Enter 'pip install numpy' into your terminal
- matplotlib.pyplot
    -Enter 'pip install matplotlib.pyplot' into your terminal 

Once you have done those three, head to the file called 'main.py' and hit the run button (looks like a triangle). This will then create a pop-up window. From there, navigate around using the bottons!

## Features
- Allows multiple users
- Creates a unique CSV for each user
- CustomTkinter User Interface
- Chart Visualizations
- Filter for Expenses from a specified time period
- Budget Limits
- Set a Savings Goal
